О проекте

Разработал frontend и backend интернет-магазина: каталог, корзину, оформление заявок и кабинет менеджеров. На сервере реализовал валидацию, роли, проверки доступа и защиту от повторного создания заказа.

TypeScript · React · Next.js · Convex · Tailwind CSS
